**Customer Segmentation Analytics Dashboard**

**Project Overview**

This project focuses on Customer Segmentation using Clustering Techniques.
The objective is to group customers based on their purchasing behavior and demographic attributes to help businesses understand customer patterns and improve marketing strategies.

The project uses machine learning algorithms and provides an interactive analytics dashboard built with Streamlit for visualizing customer segments.


**Features:-**
Customer segmentation using clustering algorithms
Interactive dashboard for data visualization
Cluster distribution analysis
Income vs spending analysis
PCA-based cluster visualization
Download clustered dataset
Easy dataset upload


**Technologies Used:-**
Python
Streamlit
Pandas
NumPy
Scikit-learn
Matplotlib
Seaborn

**Machine Learning Models Used**

The following clustering algorithms were evaluated in this project:

K-Means
Agglomerative Clustering
DBSCAN
Gaussian Mixture Model (GMM)

Each model was evaluated using the Silhouette Score to measure clustering performance.

Among these algorithms, Agglomerative Clustering produced the best clustering performance, indicating clearer separation between customer groups. Therefore, Agglomerative Clustering was selected as the final model for customer segmentation.
